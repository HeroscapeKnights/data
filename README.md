# Heroscape Knights data

The Heroscape data tables: every official army card, from Hasbro and Wizards of the Coast (2004-2011) to Renegade Game Studios (2024 onward), the products each card was sold in, pre-order bonuses, and point systems (official, original printed, and the community Delta system).

Every table will be a TSV file, so you can read it on GitHub or open it in a spreadsheet. [Heroscape Knights](https://heroscapeknights.pages.dev) is built from them.

The tables aren't published yet. This README will describe their layout and format once they are.
