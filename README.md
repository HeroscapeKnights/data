# Heroscape Knights data

The Heroscape data: every official army card, from Hasbro and Wizards of the Coast (2004-2011) to Renegade Game Studios (2024 onward), the products each card was sold in, pre-order bonuses, and point systems (official, original printed, and the community Delta system).
